Dukungan

Mulailah dengan jawaban di bawah untuk menentukan langkah terkait sinkronisasi iCloud, cadangan, pemulihan, dan pengelolaan data.

Pertanyaan umum

Apakah saya harus mendaftar?

Tidak. Anda dapat mencatat transaksi secara luring. Akun Apple yang masuk ke iCloud di iPhone hanya diperlukan jika Anda memilih sinkronisasi iCloud. App tidak pernah meminta kata sandi Akun Apple.

Apakah sinkronisasi iCloud mengunggah atau mengunduh?

Keduanya. Sinkronisasi memperbarui buku kas lokal dan cloud. Perangkat dengan Akun Apple yang sama dapat bertukar transaksi saat sinkronisasi aktif. Sambungkan internet dan biarkan App di latar depan sampai selesai. Jika ada konflik, baca petunjuk sebelum memilih data yang disimpan.

Mengapa buku kas tidak ditemukan di iCloud Drive?

App menyimpan data sinkronisasi di basis data pribadi CloudKit, bukan sebagai file yang dapat dijelajahi di iCloud Drive. Untuk membuat file yang dapat Anda kelola sendiri, gunakan Pengaturan → Sinkronisasi dan cadangan → Ekspor cadangan.

Apakah mematikan sinkronisasi atau menghapus cloud akan menghapus data ponsel?

Mematikan sinkronisasi tidak menghapus data lokal atau cloud yang sudah ada. Hapus buku kas iCloud adalah tindakan terpisah yang perlu dikonfirmasi; tindakan ini menghapus buku kas cloud App tetapi mempertahankan buku kas lokal, cadangan pemulihan, dan file ekspor. Matikan sinkronisasi di perangkat lain lebih dahulu.

Bagaimana memulihkan data di ponsel baru atau setelah data lokal hilang?

Jika buku kas cloud masih ada, pasang App di ponsel dengan Akun Apple yang sama, aktifkan sinkronisasi iCloud, dan ikuti petunjuk. Anda juga dapat memulihkan cadangan ekspor yang valid. Jika penghapusan sudah disinkronkan ke cloud, sinkronisasi tidak menyediakan versi lama secara otomatis; gunakan cadangan valid sebelum penghapusan.

Apa yang terjadi saat memilih Pulihkan cadangan?

Cadangan yang dipilih menggantikan buku kas saat ini. App menampilkan pratinjau, meminta konfirmasi, menyimpan cadangan pemulihan terlebih dahulu, lalu mematikan sinkronisasi. Periksa data sebelum mengaktifkan kembali. Cadangan JSON ekspor tidak memiliki enkripsi kata sandi tambahan; simpan dengan aman.

Bagaimana cara menghapus cadangan pemulihan?

Di Pengaturan → Sinkronisasi dan cadangan, pilih cadangan pemulihan lalu Hapus cadangan, atau pilih Hapus semua cadangan pemulihan. Penghapusan perlu dikonfirmasi, tidak dapat dibatalkan, dan tidak memengaruhi buku kas saat ini. Hapus file yang diekspor ke File secara terpisah di lokasi penyimpanannya.

Apa yang dapat dilakukan jika sinkronisasi gagal?

Periksa internet, status masuk iCloud, dan ruang tersedia, lalu kembali ke App dan coba lagi. Jika App melaporkan akun berbeda, hindari berulang kali mengganti akun atau menimpa data. Simpan pesan kesalahan dan jelaskan langkah Anda kepada dukungan. Jangan hapus App atau data cloud hanya untuk memecahkan masalah.
