Frequently asked questions

Do I need to register?

No. You can record transactions offline. An Apple Account signed into iCloud on your iPhone is needed only if you choose to enable iCloud sync. The app never asks for your Apple Account password.

Does iCloud sync upload or download?

Both. Sync updates the local and cloud ledger. Devices using the same Apple Account can exchange records when sync is enabled. Connect to the internet and keep the app in the foreground while sync completes. If a conflict appears, read the prompt before choosing which data to keep.

Why can't I find the ledger in iCloud Drive?

The app stores synced data in a CloudKit private database, not as a browsable file in iCloud Drive. To create a file you can keep and manage yourself, use Settings → Sync & backup → Export backup.

Will turning sync off or clearing the cloud delete phone data?

Turning sync off does not delete local or existing cloud data. Clear iCloud ledger is a separate action requiring confirmation. It clears this app's cloud ledger while keeping the local ledger, recovery backups, and exported files. Turn sync off on other devices first.

How can I recover data on a new phone or after local data is lost?

If the cloud ledger still exists, install the app on a phone using the same Apple Account, enable iCloud sync, and follow the prompts. You can also restore a valid exported backup. If a deletion has already synced to the cloud, sync does not automatically provide an older version; use a valid backup from before the deletion.

What happens when I restore a backup?

Restoration replaces the current ledger with the selected backup. The app shows a preview, asks for confirmation, and saves a recovery backup first. Sync is turned off afterward. Check the restored data before enabling sync again. Exported JSON backups have no additional password encryption; keep them secure.

How do I delete recovery backups?

In Settings → Sync & backup, select a recovery backup and choose Delete backup, or choose Delete all recovery backups. Deletion requires confirmation and cannot be undone. It does not affect the current ledger. Delete files you exported to Files separately at their saved location.

What can I do if syncing fails?

Check your internet connection, iCloud sign-in, and available storage, then return to the app and retry. If the app reports a different account, avoid repeatedly switching accounts or overwriting data. Keep the error message and describe your steps when contacting support. Do not delete the app or clear cloud data just to troubleshoot.
